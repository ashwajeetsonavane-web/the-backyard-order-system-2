# THE BACKYARD — Vercel + Supabase

This version is built for Vercel serverless functions. Orders are stored in Supabase; no orders.json is used.

## Vercel environment variables
- SUPABASE_URL = your Supabase project URL (no /rest/v1)
- SUPABASE_SECRET_KEY = your Supabase `sb_secret_...` key (server-side only; never expose in frontend)
- ADMIN_KEY = your private admin password
- ADMIN_WHATSAPP = 917397964842 (optional)
- WHATSAPP_TOKEN = optional Meta WhatsApp Cloud API token
- WHATSAPP_PHONE_NUMBER_ID = optional Meta WhatsApp phone number ID

## Supabase SQL
Run the following in SQL Editor:

create table if not exists public.orders (
  id bigint generated by default as identity primary key,
  order_id text unique not null,
  customer_name text not null,
  phone text not null,
  location text not null,
  payment_method text not null,
  items jsonb not null,
  subtotal numeric not null,
  total numeric not null,
  status text not null default 'NEW',
  note text default '',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

alter table public.orders enable row level security;

-- The Vercel API uses the server-side secret key, so no public table policies are required.

If your existing table was created from an earlier version, run:

alter table public.orders add column if not exists note text default '';
alter table public.orders add column if not exists updated_at timestamptz not null default now();
